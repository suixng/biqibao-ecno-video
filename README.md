# 比奇堡财经视频 Skill

把抽象的财经、商业、消费与职场话题，做成观众听得懂、画面跟得上的中文叙事动画。

从角色的具体选择切入，用动作、道具和结果解释机制，再把概念带回现实。支持从零制作，也支持接着已有文案、配音或素材继续完成。

## 成片示例：一分钟看懂机会成本

“免费汉堡，可能比买的还贵。”派大星排队领汉堡，却放弃了搬箱子赚钱的机会。

示例展示完整交付形态，具体台词、角色姿态和镜头数量不作为其他选题的固定模板。

## 能做什么

- **写文案**：具体冲突开场，角色困境解释机制，现实问题收束。
- **做分镜**：逐句明确观众需要看懂的关系、角色动作、独立道具、最终位置和入场顺序。
- **准备素材**：检查已有资产是否适合台词，补齐缺失姿态和道具，检查透明边缘。
- **配中文旁白**：生成或接入中文配音，以实际语音时间戳对齐字幕和画面。
- **制作成片**：使用 Remotion 分层剪辑，完成短预览、画面抽检、音频检查和视频导出。

默认使用比奇堡角色体系、16:9 横版、1080p、30fps、中文口播与底部字幕。角色体系、时长、画幅和声音均可按需求调整。

## 制作流程

1. **确定需求和已有材料**：读取用户的选题、文案、配音、字幕与素材，明确目标时长、画幅、角色和审核节点。只检查本次任务需要的工具。
2. **写出角色故事**：用具体冲突开场，让角色的选择与后果解释机制，再给出概念、成立条件和现实映射。
3. **拆成可执行分镜**：每句台词对应明确的动作、道具和画面关系；先规划最终位置，再标记各元素的入场触发词与素材缺口。
4. **准备并检查素材**：复用语义匹配的资产，按需生成独立角色姿态、道具和背景。检查透明边缘、风格一致性及代表性镜头，确认后扩展整片。
5. **生成中文配音并同步画面**：使用用户音频或中文TTS，以实际词句时间戳调整分镜、字幕和数字出现时间；配音在本地工程内保留。
6. **剪辑、验收和导出**：用Remotion组合图层，先检查短预览，再导出含配音的MP4；核对分辨率、时长、字幕、声音和完整解码，交付实际检查结果。

需要逐阶段审核时，每阶段展示可检查的结果再继续。已经要求直接做成片时，在授权范围内连续完成；局部修改只重做受影响部分。

## 下载后能否直接使用？

本仓库提供给AI Agent使用的制作规范、模板、校验脚本和成片示例。下载并让支持Skill的Agent加载后，可以开始写文案、做分镜；从零生图并导出完整视频，还需要可用素材或生成服务，以及本地剪辑环境。

| 想做的事情 | 下载后还需要什么 |
| --- | --- |
| 看示例视频 | 支持MP4的播放器；视频已经包含中文配音 |
| 写文案、做分镜 | 能加载Skill的AI Agent，无需即梦或本地视频工具 |
| 使用已有图片制作 | 用户提供可用角色图、道具与背景；需要透明处理时准备相应工具 |
| 从零生成图片 | 至少一种Agent可调用的生图方式，例如当前宿主可用的生图工具，或已配置的即梦CLI |
| 抠图与透明裁切 | 可直接使用的透明PNG，或可用的抠图、裁切工具；生图服务不一定直接输出真实透明底 |
| 生成中文配音 | 用户音频，或可用的中文TTS服务；使用Edge TTS需安装对应工具并能访问其网络服务 |
| 剪辑并导出MP4 | Node.js、Remotion项目依赖、可运行的Chromium、ffmpeg、ffprobe和中文字体 |
| 运行素材清单校验 | Python 3 |

### 即梦CLI是否必须配置？

**不是必须。** 已有合适素材，或Agent已有可用的生图工具时，可以不用即梦。

如果选择即梦来生成图片，需要另外安装并配置其CLI、完成本人账号登录，并具有可用生成额度。本机核对的命令入口是 `dreamina`；具体安装包、版本和参数以所使用的CLI发行说明和 `dreamina -h` 为准，不能仅凭产品名称假定命令叫 `jimeng`。

本仓库不附带即梦CLI、登录态、生成额度、其他人的API密钥，也不附带可供所有镜头复用的完整角色素材库。按所需路线配置工具后，由Agent调用；下载Skill本身不会自动开通这些能力。

### 首次使用

先让Agent检查当前任务需要的素材、工具和登录状态，列出缺失项。只做文案、分镜时直接开始；需要生图、配音或渲染时，再准备对应环境。已有Remotion项目优先复用，没有项目时需先初始化并安装依赖。

机会成本示例复用了本机已有角色素材，并使用代码绘制部分道具；它不代表已经在全新电脑上验证了“下载后无需配置即可从零完成整片”。具体配置路线和检查方法见 [工具与首次配置](references/setup.md)。

## 交付内容

按任务范围提供：中文文案、分镜、素材清单、字幕、可编辑工程、含中文配音的MP4和验收记录。只要求文案或分镜时，交付到对应阶段。

配音源文件保留在制作工程中，用于同步和修改。仓库公开示例提供带声音的视频、预览图、文稿和字幕，不单独上传配音文件。
