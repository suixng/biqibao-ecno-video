# 中文配音与同步

## 选择声音

优先使用用户提供或指定的中文配音。没有指定服务时，选当前环境可用的中文 TTS；不要为了固定某个供应商而无故阻塞任务。

一种可用实现是 Edge TTS 的 `zh-CN-YunxiNeural` 中文普通话男声。它依赖网络服务，先检查当前可用性；音色、语速和付费服务遵从用户选择。将服务名称、音色ID与实际参数记录在项目中。

声音方向需要确认时，先用一小段真实文稿试听；用户已授权直接制作且没有指定音色时，可以说明所选中文声音并继续。

## 生成与保存

将确认的文稿送入TTS，保留独立音频及服务返回的词级或句级时间戳。分段生成时，用完整意群分段，拼接后检查停顿和衔接。

使用 Edge TTS 的示例：

```bash
edge-tts --voice zh-CN-YunxiNeural --file narration.txt   --write-media narration-zh.mp3 --write-subtitles narration-zh.srt
```

此命令生成旁白与字幕文件；需要词级触发时，应使用服务实际提供的词级事件，或对最终音频做强制对齐。不能把按字数均分的时间当成精确语音时间戳。

## 以最终音频锁定时间

1. 核对朗读内容，尤其是人名、数字、缩写、多音字和长停顿。
2. 获取最终音频的实际时长和词句边界，再更新分镜。
3. 字幕按意群组织；同一组时间戳同时驱动画面触发词和数字标签。
4. 使用用户音频时保持原节奏，除非用户要求改变。

音频变速、裁剪或插入停顿后，重新对齐，或对所有时间戳做同一变换后复核。不能只改音频而保留旧字幕时间。

要求精确一分钟时，优先调整冗余文案和停顿；轻微变速需保持自然，不能强行截掉结尾。结尾可留短暂停顿，但不能用大段空白凑时长。

## 声音验收与无声问题

- 核对最终 MP4 存在预期音轨、时长覆盖旁白、没有明显截断。
- 检查非静音信号、整体响度和峰值；音量不足时调整，避免削波。
- 在可用播放器中检查开头、中段、结尾，确认确实是中文旁白且与画面同步。
- 如果当前环境不能实际听验，记录已做的机器检查及尚未完成的试听，不把音轨存在当作可听性结论。

用户反馈没有声音时，检查实际交付文件，从该文件提取独立音轨供试听，并核对播放器静音、音量及格式兼容性。检查结果尚不能定位原因时，如实说明，不先假定是用户设备问题。

配音源文件保留在本地工程中，便于同步与后续替换。用户要求试听、单独音频，或需要诊断无声问题时再提供；公开示例默认使用已经合入中文配音的视频。
