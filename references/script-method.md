# 文案方法

## 从一个可讲清楚的机制开始

先写一句“看完后，观众应该明白什么”。一分钟短片通常集中解释一个机制；多个术语只有在确实帮助理解时才加入。

例如：机会成本是为了一个选择，放弃的最佳可行替代方案的价值。

## 叙事顺序

1. **具体冲突**：前两秒给出值得继续听的结果、矛盾或疑问。
2. **角色困境**：角色面临什么选择，有哪些资源或时间限制？
3. **动作与后果**：角色做了什么，获得什么，放弃什么，为什么？
4. **概念命名**：观众看懂后，再给出术语和准确解释。
5. **现实映射**：给出同构的日常场景，保留原机制的边界。
6. **判断问题**：以观众下次能使用的问题收束。

这些是叙事功能，不必写成六个固定段落。时长较短时可以合并，不能用套话填满。

## 角色承担什么功能

| 功能 | 默认角色 | 写法 |
| --- | --- | --- |
| 经营者、规则制定者 | 蟹老板 | 用菜单、排班、收费或交易动作制造具体条件 |
| 普通行动者 | 海绵宝宝 | 有目标、有行动，也会遗漏信息 |
| 常见直觉误区 | 派大星 | 把常见误解说出来，再展示后果 |
| 观察与反问 | 章鱼哥 | 指出矛盾，避免代替作者长篇讲道理 |
| 专业与实验 | 珊迪 | 用可见的比较、实验或数据说明机制 |

只使用故事需要的角色，不为凑齐人物而加戏。更换角色体系时保留叙事功能，重新设计符合新角色的行为。

## 示例：机会成本

**较弱开场**：“今天我们来学习一个经济学概念，叫机会成本。”

**具体开场**：“免费汉堡，可能比买的还贵。”

随后把机制落在选择上：排队一小时能拿到汉堡；同一小时也可以搬箱子赚三十块。只有当搬箱子是最佳可行备选时，放弃的三十块才是这个选择的机会成本。

补上边界：“如果他更需要休息，最好的备选也可能是睡觉。”不能把机会成本一律等同于工资，也不能把所有互斥选项的收益相加。

收束：“我放弃的最好选择，是什么？”

完整示例见 `examples/opportunity-cost/narration.txt`。

## 时长与事实

初稿按目标时长控制信息量，实际朗读后再调整。句子长短、停顿和音色都会影响时长，不能只靠字数承诺精确秒数。

涉及现实事件、研究、奖项或价格时，记录可核对的来源。故事中的数字如果只是教学假设，要在文稿备注中标明，不伪装成现实数据或原剧剧情。

压缩文案时先删重复解释，保留成立条件和因果链。不要为了更有冲突而把条件结论改成绝对事实。
