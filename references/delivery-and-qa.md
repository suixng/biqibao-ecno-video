# 成片验收与交付

## 渲染前

- 文案的事实、假设与成立条件已区分。
- 素材清单中的引用、槽位和角色复用声明通过校验。
- 新素材在深色底和最终背景上检查过，Alpha轮廓、基线、间距正常。
- 台词、字幕、元素和数字使用同一时间基准。
- 多组镜头检查首组到位、最后一组到位及中段停留状态。
- 开场、转折、双组、三组、金句和结尾已检查；素材或时序有实质变动时，先检查受影响的短预览。

抽帧用来检查构图，播放用来检查动作、停顿和同步，两者不能互相替代。依据当前任务填写 `templates/qa.md`，区分通过、待检查、不适用和失败。

## 渲染后

检查实际交付的最终文件，而不只是工程预览或中间版本。

```bash
ffprobe -v error -show_entries   format=duration:stream=codec_name,codec_type,width,height,r_frame_rate,duration   -of json final.mp4

ffmpeg -v error -i final.mp4 -f null -

ffmpeg -hide_banner -i final.mp4 -vn -af volumedetect -f null -
```

核对分辨率、帧率、时长、视频和音频流、解码错误以及音量。`volumedetect`只能说明音量分布，不能证明发音正确、同步准确或用户播放器一定能正常发声。

在可用播放环境中检查成片开头、中段与结尾。无法完成的检查必须标明，不写成“全部验收通过”。

## 问题定位

| 发现的问题 | 优先处理 |
| --- | --- |
| 动作、表情与台词不符 | 更换素材或重新设计这一镜 |
| 白边、底色残留 | 修正抠图或重新生成素材 |
| 数字提前、字幕不同步 | 修正最终音频对应的时间戳 |
| 构图拥挤、遮挡字幕 | 调整信息组、槽位、尺寸与安全区 |
| 配音无声或音量过低 | 检查最终文件并提取音轨，定位编码、音量或播放问题 |
| 个别镜头生成失败 | 只重做该资产和受影响镜头 |

## 默认交付

完整成片任务交付：含中文配音的MP4、字幕、可编辑工程、文案、分镜、素材清单和验收记录。配音源文件保留在工程中，按用户需求单独提供。用户只要求其中一部分时，以其范围为准。

交付说明写明实际时长、分辨率、配音语言和检查范围，并提供可直接打开的文件。不要把只有标题和标签的无声画面描述为完整口播视频。

共享或打包工程前，清理个人绝对路径、临时缓存和密钥。成片示例可按用户指定范围单独提供，不要求同时分发全部制作素材。
