# 工具与首次配置

## 能力边界

Skill是Agent执行任务时使用的工作规范，不是包含所有依赖的独立视频软件。仓库包含文本规范、模板、素材清单校验脚本、行为评测用例和成片示例；不包含完整Remotion项目模板、角色素材库、生图服务、TTS运行环境或账号登录态。

开始任务时区分“指令已加载”“工具已安装”“服务已登录”“实际任务已成功”，不能混为一谈。

## 按任务选择路线

| 路线 | 需要准备 | 可以先做 |
| --- | --- | --- |
| 文案与分镜 | 能读取并执行本Skill的Agent | 直接写作和规划 |
| 已有素材制作 | 图片、中文音频或TTS、Remotion与媒体工具 | 盘点素材、设计分镜 |
| 需要新图片 | 宿主生图工具，或另一种已配置的生图服务；必要时另配抠图工具 | 先完成文案、分镜和提示词 |
| 即梦生图 | 即梦CLI、本人账号登录、可用额度与网络 | 先检查CLI帮助与已有素材 |

不能仅凭存在工具名称就认定可用。是否成功应以当前任务的实际返回结果判断；付费生成遵从用户授权和所用工具的规则，不为检查配置自动提交消耗额度的任务。

## 图片与透明素材

优先使用语义匹配的已有素材。需要新图时，先确认当前宿主是否确实提供可调用的生图工具，以及是否接受参考图、输出什么格式。

使用其他生图服务时，配置该服务所需的工具与认证。真实透明PNG可直接验收；输出普通背景图片时，还需要合适的抠图方式。角色包含接近背景色的细节时，简单色键可能损伤轮廓，必须检查实际结果。

生图和抠图是不同能力，不能假定配置了即梦就自动完成透明处理。

## 选择即梦时

本机验证过的CLI入口是 `dreamina`。仓库不附带它，也不预设所有发行渠道使用同一安装命令。先按所用发行版的安装说明完成安装，再读取当前帮助：

```bash
dreamina -h
dreamina login -h
dreamina text2image -h
dreamina image2image -h
dreamina query_result -h
```

需要登录时，依照CLI的登录流程完成本人账号授权；已有可用登录态则复用。不要复制作者的登录文件、密钥或会话。

提交前确认实际支持的模型、参数、用户授权和额度。异步任务返回提交ID只代表受理，需要查询到成功并保存有效图片，才算素材生成完成。不要对仍在运行的任务重复提交。

## 中文配音

用户已有音频时直接读取；否则准备一种当前可用的中文TTS工具或服务。使用Edge TTS时，需要可运行的 `edge-tts` 工具及对其服务的网络访问；其他TTS服务按实际接口配置。

本仓库提供配音和同步规范，不附带TTS可执行程序或账户权限。音频生成后再取得时间戳、检查内容和时长；详细执行方法见 [中文配音与同步](voice-and-timing.md)。

## Remotion与导出

先检查Node.js、项目依赖、Chromium、ffmpeg、ffprobe和中文字体。可用已有工程时沿用；新项目需先初始化Remotion并安装匹配版本的依赖，不依赖作者电脑上的node_modules软链接或字体绝对路径。

常用的本地版本检查：

```bash
node --version
npm --version
ffmpeg -version
ffprobe -version
python3 --version
```

版本命令成功不代表渲染已可用。项目依赖准备好后，在项目目录运行该项目的Remotion CLI，先做一个代表帧或短预览，验证浏览器可启动、图片可读取、中文字体可显示，再渲染整片。

只做文案分镜不需要通过这些检查；素材清单校验脚本需要Python 3。缺少中文字体时先配置替代字体并验证，避免导出方框字。
