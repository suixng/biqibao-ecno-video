# 素材、抠图与成片验收

## 素材原则

- 一个生成任务只描述一个角色动作或一个独立道具。不要让模型在一张图里生成多个角色、多个备选动作或完整场景拼图。
- 角色图应包含单一角色、清楚姿态/表情、完整轮廓、安全边距；手持或正在操作的核心物件应随角色保留。
- 独立进入、替换、变价或移动的物件单独生成。场景内的门、货架、路牌、柜台等也可作为可摆位元素，而不是烘焙进固定背景。
- 固定背景 `BG00` 只承载世界观；通常降低不透明度和饱和度，避免抢前景。

## 抠图与裁切

先保留原图，再制作工作用的透明底裁切图。不要用透明画布尺寸做布局：必须按 Alpha 可见主体边界裁切，并用裁切后的边界确定缩放、基线和碰撞。

每张新切图分别合成到深色底和最终背景上检查。蓝绿溢色、白边、残留白牌、背景矩形、错误的额外手臂或内置无关物都不合格，必须重做抠图或重新生成。

## 成片前清单

- 每句台词与画面新元素的出现顺序一致。
- 每个数字只在旁白念到该数字时出现。
- 一张角色姿态不会跨不同语义单元复用为主视觉，除非明确授权。
- 同时活跃的信息组不超过三个；角色内置互动道具不会与相同的独立道具重复叠加。
- 多元素单元在“首个到位、最后一个到位、中段停留”至少各检查一帧。
- 检查 Alpha 轮廓不碰撞、基线一致、主体占比合理、字幕不压主体。
- 抽检开头、每个章节转换、双组、三组、文字页和结尾，再渲染完整视频。

```bash
python3 scripts/validate_asset_manifest.py templates/asset-manifest.json
```
